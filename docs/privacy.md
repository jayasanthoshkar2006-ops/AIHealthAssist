# HealthAssist AI - Privacy & Safety Policy

## Data Privacy Principles

1. **User Ownership**: Users have absolute ownership over their stored health metrics, logs, and reflections.
2. **Data Export & Deletion**: One-click JSON data export and permanent account deletion endpoints are accessible in the UI under Settings.
3. **API Key Security**: Frontend code contains zero API keys or secrets. All external integrations are managed through backend environment variables (`.env`).
4. **Offline Architecture**: Core operations function completely offline using local database instances and local AI heuristic models.

## Medical Safety Disclaimer

HealthAssist AI is an intelligent lifestyle management and organization tool. It does not provide clinical diagnosis, prescribe medications, alter medical treatments, or replace professional medical consultations. Regulatory disclaimers are visibly displayed across all application views.
